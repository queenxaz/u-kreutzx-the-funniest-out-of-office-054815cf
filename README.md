The funniest one-line out-of-office auto-reply. Written by a small deterministic Python program. It writes a single line to `/output/entry.txt` — no network, no randomness, no model calls.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The output is byte-identical on every run: the same fixed line, UTF-8, no trailing newline.
